# Selected Object Coordinates

Live coordinates for selected objects in the Geometry Dash editor.

Open a level in the editor and select one object. Its X and Y appear at the top of the screen; moving it updates the readout automatically. Deselect to hide it. Multi-selections show the count.

Built for GD 2.2081 using Geode SDK 5.8.2. Android64 and Win64 packaged together by GitHub Actions.
